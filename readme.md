# CareDose+ - Smart Medication Management

A professional medication management system designed for healthcare providers to efficiently track patient medications, appointments, and adherence.

## Features

- **Patient Management**: Comprehensive patient profiles with medical history
- **Medication Tracking**: Real-time medication adherence monitoring
- **Appointment Scheduling**: Manage patient appointments and reminders
- **SMS Communication**: Automated medication reminders and patient communication
- **Voice Call Integration**: Voice-based medication alerts and follow-ups
- **Refill Management**: Smart medication refill tracking and alerts
- **Dashboard Analytics**: Visual insights into patient adherence and health metrics

## Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Shadcn UI
- **Backend**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Real-time**: Supabase Realtime
- **SMS/Communication**: Twilio Integration
- **Charts**: Recharts
